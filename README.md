# Samad Ayomide Musa - Portfolio Website

A modern, responsive portfolio website for a Data Scientist & Machine Learning Engineer.

## 🚀 Features

- **Dark Theme** with purple gradient accents
- **Typing Effect** hero animation
- **Scroll Reveal** animations on all sections
- **Animated Skill Bars** with intersection observer
- **3D Tilt Effect** on project cards
- **Parallax Orbs** that follow mouse movement
- **Mobile Responsive** with hamburger menu
- **Contact Form** ready for Formspree integration
- **Smooth Scrolling** navigation

## 📁 Files

| File | Description |
|------|-------------|
| `index.html` | Main HTML structure |
| `style.css` | All styling (no external CSS framework) |
| `script.js` | Interactivity & animations |
